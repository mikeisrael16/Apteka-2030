# Нижневартовск 2030: «Аптека»

Вертикальная мобильная игра от **Mikhail Game Studio**. Вы — провизор Государственного Аптечного Пункта №4 в Нижневартовске после ядерной войны: проверяете документы, меряете фон дозиметром, выдаёте лекарства строго по талону — или нет.

**Играть:** https://mikeisrael16.github.io/Apteka-2030/

## Что есть
- Стартовое меню: Новая игра / Продолжить (автосохранение) / Загрузить (ручное сохранение)
- День 1 — обучающая смена: майор Коршунов, Пётр Ильин, Анна Котова, Виктор Захаров
- День 2 — Клавдия Морозова, Глеб Руднев, Артём Белов, чёрный рынок Ворона и ревизия капитана Громова
- День 3 — Вера Лебедева, Мария Аркадьевна, Фёдор «Зверь», звонок из дома (дочка Алина) барыга Семён «Рваный» и Ворон
- Дни 5–6 — паспортный режим и перепись населения, призыв сына Данила, третья ревизия
- День 4 — письмо от Оли, Егор Петрович, Вадим «Беглец», Анна Васильевна, Тимоха «Гвоздь» и ревизия капитана Громова
- Пауза с сохранением, музыка и звуки (синтез Web Audio)
- Два языка: русский и английский (Nizhnevartovsk 2030: Pharmacy). Язык выбирается по настройкам телефона, переключается флажками в меню

## Структура
- `index.html` — готовая игра одним файлом (все картинки внутри)
- `src/index.src.html` — исходник; `src/assets/` — спрайты
- `src/build.py` — собирает `index.html` из исходника и спрайтов (нужен Node.js + `npm i acorn` в `src/tools`)
- `src/i18n/` — перевод: `keys_ru.json` (все русские строки), `en_*.txt` (английский по номерам), `check.py` — проверка
- `src/tools/i18n.js` — при сборке оборачивает русские строки в `_()`; `src/parts/i18n_rt.js` — словарь и переключение языка
- `src/test_playthrough.py` — автотест всех веток (Playwright)
