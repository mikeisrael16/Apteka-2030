# Нижневартовск 2030: «Аптека»

Вертикальная мобильная игра от **Mikhail Game Studio**. Вы — провизор Государственного Аптечного Пункта №4 в Нижневартовске после ядерной войны: проверяете документы, меряете фон дозиметром, выдаёте лекарства строго по талону — или нет.

**Играть:** https://mikeisrael16.github.io/Apteka-2030/

## Что есть
- Стартовое меню: Новая игра / Продолжить (автосохранение) / Загрузить (ручное сохранение)
- День 1 — обучающая смена: майор Коршунов, Пётр Ильин, Анна Котова, Виктор Захаров
- Пауза с сохранением, музыка и звуки (синтез Web Audio)

## Структура
- `index.html` — готовая игра одним файлом (все картинки внутри)
- `src/index.src.html` — исходник; `src/assets/` — спрайты
- `src/build.py` — собирает `index.html` из исходника и спрайтов
- `src/test_playthrough.py` — автотест всех веток (Playwright)
